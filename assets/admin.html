      Backup and restore

      JSON holds the memories, the board, the files and the profile: portable, and it can be merged into another lore. The full database is everything, an exact copy.

      JSON backup

      Full database (.sqlite)

      Restoring replaces everything here with the uploaded database, its users, passwords, permissions and agent tokens included, so it is only for users who hold every permission. Restoring an older backup brings back deleted users and old passwords; its passkeys, authenticator apps and recovery codes replace today's, and a backup from before these existed removes every second step and lets the built-in users in with the environment passwords again. A safety copy of the current database is kept on the server first.

              Agents

              Agents connect with a token from the server environment, or by authorizing through OAuth: add this server's /mcp URL to the client without a token and approve it in the browser page that opens.

              Built-in agents

              Claude Code, Codex, and opencode (DeepSeek, OpenCode Go, and Claude or GPT models through their APIs) in their own containers next to lore. Sign each in once with your own subscription or key; the credential stays in that agent's volume and never reaches lore's database.

                Task runner

                An enabled agent takes an open, unclaimed task nobody touched for a while, works on it in a fresh clone of the task's repository and pushes to its default branch. It may change only that repository (and the Dokploy project or Cloudflare zone the task names). A run that fails or is stopped releases the task with a note, and the task is not taken again until someone touches it.

                              • Cloudflare Not set

                              • GitHub (personal) Not set

                              • Organization token Not set

                                GitHub (organization): kept apart from the personal token, used by the github_org tool and by clones through /git/github-org/.

                              • GitLab (self-hosted) Not set

                              • Dokploy Not set

                              • Mailbox (IMAP, read-only) Not set

                                IMAP access over TLS, for reading only: agents may list folders and messages and read them. lore never sends, moves, deletes or marks mail. Each agent sees the mailbox only after its mail level is set to read below. Many providers need an app password here, not the account password.
